# P4DE — Platform 4 Desktop Environment

P4DE is the name of NotreOS's desktop environment. In Ancient 0.0.1, P4DE is an intentionally small graphical session managed by NotreInit: it starts X.org on the first virtual terminal and opens Dillo to the local NotreOS welcome page.

This first edition does not yet contain a standalone window manager, panel, application menu or settings app. NotreShell remains available on VT2, independently of the graphical session. Naming and visual polish can evolve while preserving the P4DE identity.
