# NotreOS Ancient roadmap

## Ancient 0.0.1 — current work

Complete the first x86_64 UEFI build, the NotreOS-authored bootloader, init and shell, and the minimal P4DE session. Stabilize the build and verify the boot path before expanding scope.

## Ancient 0.1.0 — next milestone

The goal for Ancient 0.1.0 is to be usable day to day on older computers. Before claiming that goal, document a concrete minimum-hardware baseline and test the release against it; the exact baseline has not been selected yet.

Development of the separate NotreOS Core edition begins at the Ancient 0.1.0 milestone. That future track does not divert work from completing Ancient 0.0.1.
